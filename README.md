# Fish Portfolio

刘宇林（Fish）的 UI、AI、动画与产品设计作品集。

## 本地运行

```bash
npm install
npm run dev
```

## 发布到 GitHub Pages

1. 在 GitHub 新建公开仓库，建议命名为 `fish-portfolio`。
2. 将本项目全部文件上传到仓库的 `main` 分支。
3. 进入仓库 Settings → Pages。
4. Source 选择 GitHub Actions。
5. 等待 Actions 中的部署任务完成。

网站地址将是：`https://你的用户名.github.io/fish-portfolio/`
